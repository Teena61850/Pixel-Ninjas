# 📝 Brief Description

Neon Orb Frenzy Deluxe is a fast-paced arcade-style browser game where players compete against time to score the highest points by popping neon orbs, collecting power-ups, maintaining combo streaks, and avoiding dangerous obstacles.

Set in a vibrant cosmic environment with animated visuals, sound effects, achievements, and leaderboard functionality, the game delivers an exciting and engaging experience for players of all skill levels.

---

# 🎯 Objective and Rules

## Objective
Achieve the highest possible score within **60 seconds** by popping beneficial orbs, collecting power-ups, and maintaining combo multipliers.

## Rules

- Each player starts with **5 lives**.
- The game lasts **60 seconds**.
- Click positive orbs to gain points.
- Avoid red danger orbs.
- Collect power-ups for special abilities.
- Catch comets for bonus points.
- Lose one life when clicking a red orb.
- The game ends when:
  - Time reaches 0, or
  - All lives are lost.

---

# 🎮 How to Play

1. Launch the game.
2. Enter your player name.
3. Click **Start Game**.
4. Read the instructions screen.
5. Begin the Neon Orb Frenzy.
6. Pop scoring orbs and collect bonuses.
7. Avoid red orbs.
8. Use power-ups strategically.
9. Achieve the highest rank and score possible.

# 🏆 Scoring Rules

## Orb Scores

| Orb Type | Points |
|-----------|----------|
| 🔵 Blue Orb | +5 |
| 🟢 Green Orb | +10 |
| 🟣 Purple Orb | +15 |
| 🟡 Gold Orb | +25 |
| ☄️ Bonus Comet | +50 |
| 🔴 Red Orb | -10 Points and -1 Life |

## Combo System

- Consecutive positive orb clicks increase the combo multiplier.
- Higher combos generate significantly more points.
- Red orbs reset the combo streak unless Combo Lock is active.
- There is no upper limit for combos.

## Bonus Scoring

- Full-life heart pickup grants **+50 bonus points**.
- Double Points power-up multiplies earned points by 2.

# ⚡ Power-Ups

| Power-Up | Effect |
|-----------|---------|

| 🔥 Combo Lock | Protects combo streak |
| 👑 Golden Rush | Converts positive spawns to gold orbs |
| 💥 Orb Bomb | Pops all visible positive orbs |
| ⏱️ Slow Motion | Slows movement and extends orb lifetime |
